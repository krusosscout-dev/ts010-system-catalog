# คลังระบบออนไลน์ · ครูซอสสอนสังคม (TS010)
ศูนย์รวมนวัตกรรม สื่อการเรียนรู้ และระบบงานดิจิทัลส่วนตัวของครูซอส

---

## 🌟 จุดเด่นและฟีเจอร์ใหม่ครบวงจร (เวอร์ชันล่าสุด)

1. **📱 กล่องข้อความทันสมัย & แป้นตัวเลขพร้อมกด (Interactive Numeric Keypad):**
   - ยกเลิกกล่องข้อความ `prompt()` และ `confirm()` ดั้งเดิมของเบราว์เซอร์ทั้งหมด
   - แทนที่ด้วยโมดอลกระจก Glassmorphic สุดหรู พร้อม **แป้นตัวเลข 0–9, ปุ่มล้าง (C) และปุ่มลบ (⌫)** สำหรับกดใส่รหัส PIN ได้ทันที
   - รองรับทั้งการสัมผัสบนมือถือ/แท็บเล็ต การคลิกเมาส์ และการกดแป้นพิมพ์จริงบนคีย์บอร์ด (0–9, Backspace, Esc)
   - มีไฟแสดงสถานะ 4 จุด (PIN Dots) แบบเคลื่อนไหว พร้อมระบบตรวจจับและอนิเมชันสั่นเตือนเมื่อใส่รหัสผิด
   - กล่องยืนยันการทำรายการ (Custom Confirmation Dialog) ดีไซน์พรีเมียม สวยงาม เข้ากับธีมของระบบ

2. **👑 ส่วนหัวของระบบสไตล์ผู้บริหาร (Executive Catalog Header Banner):**
   - ออกแบบแถบส่วนหัวใหม่ให้สวยเด่น มีระดับ สอดรับกับโทนสี Dark Slate / Indigo ของแถบเมนูด้านซ้ายอย่างกลมกลืน
   - แถบสถานะด้านบนแสดง Workspace Tag: `TS010 · แพลตฟอร์มคลังระบบดิจิทัล / ครูซอสสอนสังคม`
   - ป้ายบอกสถานะผู้ใช้งานแบบเรียลไทม์:
     - `👁️ โหมดผู้ชม (Viewer)` พร้อมปุ่มกดเข้าสู่ระบบผู้ดูแล
     - `👑 ผู้ดูแลระบบ (ครูซอส)` พร้อมปุ่มล็อกสลับเป็นโหมดผู้ชม
   - ไอคอนหมวดหมู่ไดนามิกและหัวข้อหน้าชัดเจน
   - แถบตัวกรองแท็บ (Segmented Tabs) แบบปุ่มสัมผัสนุ่มนวล พร้อมแสดงจำนวนระบบในแต่ละสถานะแบบเรียลไทม์

3. **✨ หน้าแรกมิติใหม่ จบในหน้าเดียว 100% ไม่ต้องเลื่อนจอ (Single Screen 100vh):**
   - **โลโก้ตรงกลางขยายขนาดใหญ่ขึ้นเด่นสง่า (150px)** พร้อมเพิ่มมิติแสงเรืองรอง (Dual Ambient Aura), ขอบไล่เฉดสี และอนิเมชันลอยตัว 3 มิติ (Floating Effect)
   - แบ็กกราวด์ลวดลาย Matrix Grid ทันสมัย เพิ่มมิติความลึก ไม่แบนและไม่จืดชืด
   - **แถบสรุปสถิติคลังระบบสด (Live Metrics Bar):** แสดงจำนวนระบบทั้งหมด, ระบบพร้อมใช้, ด้านงานที่ดูแล และสถิติการคลิกเข้าชมสะสม
   - **จบในหน้าจอเดียว (No Scroll):** ปรับสัดส่วนให้พอดีจอ 100vh สวยงาม สะอาดตา ไม่ต้องเลื่อนจอ
   - ทางเลือกเข้าใช้งานชัดเจน: ปุ่ม **"🚀 เข้าชมคลังระบบ (โหมดผู้ชม)"** สำหรับคนทั่วไป และปุ่ม **"🔐 เข้าสู่ระบบผู้ดูแล (รหัส PIN)"** เปิดแป้นตัวเลขทันที

4. **👁️ โหมดผู้ชมแบบสาธารณะ & พรีวิวระบบ (Public Viewer Mode & System Preview):**
   - เผยแพร่ให้ครู นักเรียน หรือบุคคลภายนอกเข้าดูและใช้งานได้อย่างมั่นใจ 100%
   - **สิทธิ์ของผู้ชม:**
     - ค้นหา, กรอง และจัดเรียงระบบทั้งหมดในคลังได้อิสระ
     - กดปุ่ม **"เปิดใช้งานจริง ↗"** เพื่อใช้งานระบบหรือแอปพลิเคชัน
     - กดปุ่ม **"ดูตัวอย่าง"** เพื่อเปิดหน้าต่าง System Preview Modal ดูภาพหน้าจอ Mockup เบราว์เซอร์, ฟีเจอร์เด่น, เทคโนโลยีที่ใช้ และป้าย QR Code
     - **ห้ามแก้ไข ห้ามลบ ห้ามเพิ่มระบบ:** ปุ่มเพิ่มระบบ, แก้ไข, ลบ และการตั้งค่าจะถูกล็อกไว้ หากกดจะแสดงแป้นตัวเลขขอรหัส PIN ของครูซอส
   - **สิทธิ์ของผู้ดูแลระบบ (ครูซอส):**
     - ใส่รหัส PIN เพื่อปลดล็อกสิทธิ์เต็มรูปแบบ สามารถเพิ่ม แก้ไข ลบ จัดการหมวดหมู่ และตั้งค่าระบบได้อย่างสมบูรณ์

5. **🔥 ระบบยอดนิยม & บันทึกสถิติการเข้าใช้งาน (Click Counter & Trending):** นับสถิติการคลิกเปิดใช้งานระบบอัตโนมัติ พร้อมจัดอันดับระบบที่มีคนเข้าใช้มากที่สุด
6. **⌨️ Spotlight Quick Search (Ctrl + K):** ค้นหาระบบได้ทันทีด้วยคีย์ลัด หรือคลิกแถบค้นหา มีผลลัพธ์ด่วนกดคลิกเปิดได้ในเสี้ยววินาที
7. **📢 แถบประกาศสำคัญ (Announcement Banner):** แจ้งเตือนข้อความสำคัญหรืออัปเดตระบบแก่ผู้เข้าชม สามารถเปิด-ปิดและแก้ไขข้อความได้ในการตั้งค่า
8. **📲 ติดตั้งใช้งานแบบแอปพลิเคชัน (PWA Support):** รองรับ Progressive Web App สามารถกดติดตั้งลงหน้าจอโฮมบนมือถือ (iOS/Android) และคอมพิวเตอร์
9. **🖨️ สร้าง QR Code พร้อมป้ายชื่อระบบทันที:** สร้าง QR Code อัตโนมัติในคลิกเดียว พร้อมป้ายชื่อระบบและโลโก้ครูซอส
10. **เชื่อมต่อ Firebase (Cloud Firestore):** ซิงค์ข้อมูลขึ้นคลาวด์อัตโนมัติ ข้อมูลและรหัส PIN ตรงกันทุกเครื่อง

## 🔐 ข้อมูลรหัสผ่าน PIN ผู้ดูแลระบบ (ครูซอส)
- **รหัสผ่านเริ่มต้น:** `0000` (หรือสามารถใช้ `2569` ได้เช่นกัน)
- **การเปลี่ยนรหัสผ่าน:** ไปที่เมนู "ตั้งค่าระบบ" (รูปเฟือง) > หัวข้อ "รหัสผ่านผู้ดูแลระบบ (Owner PIN)" > กดปุ่ม **"เปลี่ยนรหัส PIN (เปิดแป้นตัวเลข)"**
- เมื่อตั้งรหัสใหม่แล้ว ระบบจะบันทึกทั้งในเครื่องและซิงค์กับ Firestore อัตโนมัติ ทำให้รหัสผ่านตรงกันทุกอุปกรณ์
