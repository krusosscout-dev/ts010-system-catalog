# คลังระบบออนไลน์ · ครูซอสสอนสังคม (TS010)
ศูนย์รวมนวัตกรรม สื่อการเรียนรู้ และระบบงานดิจิทัลส่วนตัวของครูซอส

---

## 🌟 จุดเด่นและฟีเจอร์ใหม่ครบวงจร
1. **อัตลักษณ์และโลโก้ครูซอส (Personal Branding):** โลโก้ครูซอสสอนสังคมแบบไดนามิก โปร่งใส สวยงาม ไร้พื้นหลัง พร้อมไอคอนแท็บ (Favicon) ประจำระบบ
2. **หน้าแรกสุดแนวสมัยใหม่ (Modern Landing Portal):** มีนาฬิกา Real-time, วันที่ภาษาไทย, สรุปสถิติแบบ Bento Grid และแถบ Quick Launch เข้าใช้งานระบบด่วน
3. **🔥 ระบบยอดนิยม & บันทึกสถิติการเข้าใช้งาน (Click Counter & Trending):** นับสถิติการคลิกเปิดใช้งานระบบอัตโนมัติ พร้อมจัดอันดับระบบที่มีคนเข้าใช้มากที่สุดบนหน้าแรก
4. **⌨️ Spotlight Quick Search (Ctrl + K):** ค้นหาระบบได้ทันทีด้วยคีย์ลัด หรือคลิกแถบค้นหา มีผลลัพธ์ด่วนกดคลิกเปิดได้ในเสี้ยววินาที
5. **📢 แถบประกาศสำคัญ (Announcement Banner):** แจ้งเตือนข้อความสำคัญหรืออัปเดตระบบแก่ผู้เข้าชม สามารถเปิด-ปิดและแก้ไขข้อความได้ในการตั้งค่า
6. **📲 ติดตั้งใช้งานแบบแอปพลิเคชัน (PWA Support):** รองรับ Progressive Web App สามารถกดติดตั้งลงหน้าจอโฮมบนมือถือ (iOS/Android) และคอมพิวเตอร์ (Windows/Mac) ใช้งานได้สะดวกรวดเร็ว
7. **🖨️ สร้าง QR Code พร้อมป้ายชื่อระบบทันที:** สร้าง QR Code อัตโนมัติในคลิกเดียว พร้อมป้ายชื่อระบบและโลโก้ครูซอส เหมาะสำหรับปริ้นต์ติดบอร์ดหรือแชร์
8. **เชื่อมต่อ Firebase (Cloud Firestore):** ซิงค์ข้อมูลขึ้นคลาวด์อัตโนมัติ ข้อมูลตรงกันทุกเครื่อง ทั้งบนคอมพิวเตอร์และมือถือ พร้อมโหมดออฟไลน์
9. **ระบบล็อกเจ้าของ (Owner PIN Lock):** ระบบใช้งานคนเดียว เมื่อนำขึ้น Vercel สาธารณะ คนอื่นจะเปิดใช้งานระบบได้เท่านั้น หากจะเพิ่ม ลบ หรือแก้ไข จะต้องใส่รหัส PIN ของครูซอส
10. **รายละเอียดระบบแบบเจาะลึก:**
    - ฟีเจอร์หลัก (Key Features)
    - กลุ่มผู้ใช้งานเป้าหมาย
    - ลิงก์คู่มือ / เอกสารแนบ (Drive / PDF)
    - เวอร์ชันของระบบ
    - โน้ตส่วนตัวของนักพัฒนา (Dev Notes)
    - บัญชีทดลอง (Username / Password) พร้อมปุ่มคัดลอก
11. **พร้อม Deploy บน Vercel:** Zero-build Architecture รันได้ทันทีโดยไม่ต้อง Compile

## 🚀 ข้อมูลการเชื่อมต่อ Firebase (Project: ts010-2bf5d)
ระบบเชื่อมต่อกับ Google Firebase Firestore ในไฟล์ `firebase-config.js` เรียบร้อยแล้ว พร้อมใช้งานบน Cloud ทันที

### 🔒 กฎความปลอดภัย Firestore (Rules ที่แนะนำ)
ใน Firebase Console > Firestore Database > แถบ **Rules**:
```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```

## ⚡ วิธีนำขึ้น Vercel ผ่าน GitHub Desktop

1. เปิดโปรแกรม **GitHub Desktop**
2. จะเห็นรายการไฟล์ที่ปรับปรุงล่าสุด (`index.html`, `logo.png`, `logo-512.png`, `favicon.png`, `manifest.json`, `sw.js`, `README.md`)
3. ในช่อง Summary พิมพ์: `Update logo and add all 4 features`
4. กดปุ่ม **"Commit to main"** แล้วกด **"Push origin"**
5. ระบบ Vercel จะดึงไฟล์ล่าสุดและ Deploy ให้อัตโนมัติทันที

## 🔐 การตั้งรหัส PIN เจ้าของระบบ
- เมื่อเปิดใช้งานครั้งแรก กดไอคอนรูปแม่กุญแจ 🔒 ที่มุมล่างซ้าย (หรือแถบเมนู)
- รหัสผ่านเริ่มต้นคือ `0000` (หรือสามารถตั้งรหัสใหม่ 4 หลักตามต้องการ)
- เมื่อล็อกแล้ว บุคคลภายนอกจะไม่สามารถกดแก้ไข/ลบ/เพิ่มระบบได้ครับ
